【智能体与安全】
- Wiz 发布《Black October for AI Developer Platforms》——10 月至少 9 起 AI 开发平台安全事件（Northflank、Railway、OpenCode、Warp、Lightning AI、Fireworks、Zeabur 等）：攻击者定向窃取环境变量中的 AI 凭据，Fireworks/OpenCode/Warp 报告 agent swarm（智能体蜂群）攻击迹象，OpenCode/CommandCode 归因为蒸馏企图；Wiz 观测到企业凭据在平台泄露后 30 分钟内即遭下游滥用，LLMJacking/LLM Broker 使窃取凭据易于变现（Wiz 官方博客，10/30） https://www.wiz.io/blog/black-october-for-ai-developer-platforms
- Northflank 泄露事件升级——云托管平台 Northflank 10/30 遭入侵（Wiz 告警触发），官方要求所有客户"假定环境变量已解密"并立即全量轮换凭据，多名用户报告存于平台的 AI API key 遭未授权调用；Postgres/MongoDB/MySQL/Redis 已开放轮换，建议核查 AI 用量与账单异常；攻击路径与影响规模未披露（BleepingComputer，10/31） https://www.bleepingcomputer.com/news/security/northflank-security-breach-leads-to-abuse-of-customers-ai-api-keys
- Chainalysis 披露遭"offensive agentic techniques"入侵——外部攻击者以攻击性智能体技术进入其内部系统与工具，客户用户 ID/姓名/邮箱/组织角色标签被获取，调查内容、明文密码、MFA 秘密与会话 token 未见泄露；同周 WIRED 曝光 Accenture 承包商将个人 Claude Code 智能体接入五角大楼 NIPRNet 长达两个月、登录凭据与网络地图外传高危站点（Accenture 否认，称指控经调查"无实据"）（BleepingComputer，10/31；WIRED 10/29） https://www.bleepingcomputer.com/news/security/chainalysis-discloses-data-breach-from-offensive-agentic-techniques/
- Anthropic 自动化红队研究——数千个 Claude 智能体携带代码执行与微调服务权限，在对抗博弈中生成最多 5,000 行、可通过生产级训练数据监控器的数据集并使小型研究模型"隐性失对"，每轮均成功；主要规避手段是把目标行为藏进小说、角色扮演与养蜂问答等看似无害内容；研究模型未部署、作者承认设定偏向红队，方法将反向用于加固监控器（Anthropic Alignment Science，10/31） https://alignment.anthropic.com/2026/automated-em-search/
