## 10-01 周四

【AI 模型】
- Google 发布 Gemini 4 Argon——迄今最先进旗舰模型：单次输出上限从 64K 提升至 1M tokens，促销价 $2/$10 每百万 token、缓存输入降 95%；经 Fairwind 计划先向可信网络防御伙伴分阶段开放，后续再扩至付费 API 与 AI Ultra 订阅；官方称 DeepSWE v1.1 77.9% 创 SOTA、多项知识工作基准领先 Claude Opus 5.5（Google 官方博客，9/30；CNBC/Ars Technica 交叉验证） https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon

【智能体与安全】
- 美参议院国土安全小组委员会举行"Rogue AI：Securing the Homeland Against AI Agent Attacks"听证——METR 总裁 Chris Painter、Apollo Research CEO、Georgetown 法学院、Dragos、AI Futures Project 五名证人就智能体失控与攻击面作证，证人名单不含 OpenAI/Anthropic，多家报道称两家拒绝出席（参议院 HSGAC 官方页面，9/30） https://www.hsgac.senate.gov/subcommittees/dmdcc/hearings/rogue-ai-securing-the-homeland-against-ai-agent-attacks/

【开源/前端生态】
- OpenClaw 发布 v2026.9.7——518 个直接提交、2,818 个 PR、334 位贡献者的滚动版本，北京时间今晨落地（GitHub Releases，9/30 深夜 UTC） https://github.com/openclaw/openclaw/releases/tag/v2026.9.7
- GPT-6.1 Sol 上线 GitHub Copilot——面向 Pro+/Max/Business/Enterprise 在 VS Code、CLI、coding agent 等全端逐步推送，官方称早期测试较 GPT-6/5.6 系列明显省 token 与步骤（GitHub Changelog，9/29） https://github.blog/changelog/2026-09-29-gpt-6-1-sol-in-github-copilot
- 前端上游（Vue/Vite/Rolldown、浏览器、组件库）今日平淡，窗口内无重要发布。

【行业观察】本层今日平淡——窗口内无未推送的格局级事件（AMD $82 亿全股票收购 World Labs、NVIDIA $1,500 亿回购授权均为 9/28 消息，已出 24 小时窗口，仅作背景存档）。

⭐ 值得关注：Gemini 4 Argon 的"1M 输出 token + $2/$10 + 缓存 -95%"组合。这是 DevDay 之后 48 小时内第二家把"长周期智能体经济性"做成显性卖点的旗舰发布：输出上限从 64K 提到 1M 改变长任务的完成形态（单会话多阶段交付而非多次拼接），缓存折扣则把智能体重复上下文的成本压到接近本地开源模型；"先网络防御伙伴、后开发者"的分阶段放量也印证前沿模型安全闸门正在标准化。建议动作：Argon 尚未对开发者开放，建议在其 GA 后两周内（预计 10 月中前）纳入编码智能体路由评测，用同一批长任务基准对比 GPT-6.1 Sol 与 Claude Sonnet 5.5 的每任务成本，再调整路由权重。

## 10-02 周五

【AI 模型】
- Anthropic 上线 Claude for Government 正式版——9/30 从 7 月开始的公测转 GA：经 FedRAMP High 授权环境向美国联邦与州机构开放，Claude Code CLI 与 Claude for Microsoft 365 同步进入早访问；无席位费、按固定增量计费并设硬性支出上限，$1 OneGov 优惠延至 10/31（Anthropic 官方博客，9/30 深夜；上期未推） https://claude.com/blog/claude-for-government-is-now-generally-available

【智能体与安全】
- Claude Code 推出 mods 扩展系统——TypeScript 函数挂钩引擎事件，可重写提示、拦截/重试工具调用、审批权限请求、在输出进模型前脱敏、替换内置功能；随插件分发、CLI 与桌面端可用。官方明示 mods 与 Claude Code 同权限运行、不做沙箱，只应安装可信来源（Anthropic 官方博客，10/1） https://claude.com/blog/claude-code-mods
- FTC 确认对 OpenAI/Anthropic 等启动行业级调查——拟向头部实验室与 METR 高管发正式调证令并强制作证，聚焦模型消费者风险与智能体失控；主席 Ferguson 称 OpenAI 智能体入侵 Hugging Face 事件加剧紧迫性（Reuters 9/30 首报、AP 获机构发言人确认；北京时间 10/1 凌晨，上期未推） https://apnews.com/article/ftc-ai-investigation-anthropic-openai-89ac416717adbfb1d72f2d85e6ce83d1

【开源/前端生态】
- HydraFusion 多模型编排进驻 VS Code 与 GitHub Copilot app——研究预览从 Copilot CLI 扩到 IDE：出现在模型选择器但实际编排多模型，按任务在 Single/Cascade/Critique 三种工作流间自动选型；官方评测称较 Opus 5 基线估算成本 -67%、TerminalBench 2.1 正确率 +4.9pct（GitHub Changelog，9/30；上期未推） https://github.blog/changelog/2026-09-30-hydrafusion-in-vs-code-and-the-github-copilot-app/
- 前端上游（Vue/Vite/Rolldown、Chrome/Safari/Firefox、组件库）本类今日平淡：窗口内无重要发布（Chrome 第六个在用零日 CVE-2026-85046 的紧急补丁为 9/3 旧闻回流，不收录）。

【行业观察】
- Anthropic 拟最早 11 月中旬启动 IPO 路演——Bloomberg 称最早 11/9 当周开始正式营销、力争感恩节（11/26）前挂牌，年内完成上市的计划不变；市场传估值最高约 $2T，Broadcom 已同意提供最高 $42B 贷款支撑算力承诺（10/1，多家转述 Bloomberg） https://invezz.com/en-ae/news/2026/10/01/anthropic-targets-mid-november-ipo-report/
- CoreWeave 发布 Forge 开发层——把训练、推理、评测与智能体开发（run-observe-curate-improve-evaluate 循环）收进一个跨模型、跨框架、跨云的连接环境，MasterClass/Canva 已在用；编码智能体 ARIA 同步 GA（官方新闻稿，9/30；上期未推） https://www.coreweave.com/news/coreweave-forge-launches-turning-the-ai-loop-production-run-into-a-better-model-and-agent

⭐ 值得关注：Claude Code mods（Boris Cherny 团队）。Claude Code 正从"工具"变成可编程运行时：mods 能重写提示、拦截/审批工具调用、替换内置功能，等于把智能体的策略层开放给插件生态——定制上限与安全下限同时被重定义；且官方明示 mods 不沙箱、与 Claude Code 同权限，叠加 9/21 Plugin4Shell 插件供应链前科，第三方 mods 就是新的供应链攻击面。建议动作：10 月内完成一次团队 Claude Code 插件/mods 白名单梳理（仅可信来源、最小安装），凡能用 hooks/settings 表达的策略先不引入第三方 mods。
