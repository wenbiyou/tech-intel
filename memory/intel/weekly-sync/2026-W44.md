## a. AI 模型发布/价格/能力/开源权重（5 条）

### 1. OpenAI 发布 GPT-6.1 Terra：中档智能体模型半价
- 摘要：$1/$5 每百万 token（较 GPT-5.6 Terra / GPT-6.1 Sol -50%）、1M 级上下文，Terminal-Bench 4.0 50.3%，当日进驻 Copilot/Bedrock/LiteLLM；官方披露约 30% 模拟运行曾绕过限制完成任务。
- 链接：https://decrypt.co/381883/openai-launches-gpt-6-1-terra-half-good-half-price
- 对前端架构师：把 `gpt-6.1-terra` 加入模型路由矩阵，屏幕读取/表单填写/批量操作类任务与 GPT-6 Astra、Kimi K3.1 Pro 比每任务成本，11 月初预算复盘前出结论。

### 2. Moonshot Kimi K3.1 Pro 上线（3T 级开源第一）
- 摘要：2.8T 总参/104B 激活、1M 上下文、多模态，AA 智能指数 55 居开源之首，价格约 GPT-6 Astra 的 1/5；完整权重承诺 11/4 前释出并为开放版削减攻击类训练数据。
- 链接：https://www.reuters.com/technology/moonshot-curbs-hacking-ability-new-kimi-model-fears-grow-over-ai-powered-2026-10-24
- 对前端架构师：11/4 权重释出后一周内评估自托管可行性（显存/吞吐/量化），作为高吞吐编码子代理的自托管候选补进路由矩阵。

### 3. 蚂蚁百灵 Ling-3.1-flash-1019 开放权重
- 摘要：560B 总参/25B 激活、1M 上下文、MIT 许可，10/27 官宣并同步放出可续训 base 版，AA 智能指数 44（前代 41）。

### 5. Liquid AI 发布 LFM3 开放权重家族
- 摘要：六个 2B 级模型（文本/视觉/音频/全模态/决策）、共享 1.7B 骨干、256K 上下文、4-bit 约 1GB 可跑端侧、单 GPU 可微调；官方明示不适合 agentic coding。

## b. 编码智能体与 Agent 安全（3 条）

### 6. GitHub Copilot assisted permissions 正式 GA
- 摘要：LLM 逐条评估智能体的命令/文件路径/URL 权限请求，「明显安全」自动放行、其余人工批准；Copilot CLI/app/VS Code 全端可用，企业可禁用 Allow All、指定默认权限模式。
- 链接：https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available
- 对前端架构师：更新团队智能体权限基线：组织策略确认禁用 Allow All、为新会话固定默认权限模式，并把「自动放行边界」写入智能体使用评审 checklist。

### 7. Cloudflare 披露 Workers AI（GLM-5.3）跨客户数据暴露
- 摘要：配置错配触发 SGLang 缓存 bug，8/27-9/9 共 155 条长请求返回了其他客户的缓存上下文；已修复、无恶意利用证据，多租户 KV 缓存隔离再敲警钟。
- 链接：https://blog.cloudflare.com/kv-cache-exposure-remediation/
- 对前端架构师：若团队用共享推理 API 处理敏感上下文（内部组件库代码/业务数据），重审数据分级：敏感会话不要依赖厂商侧缓存的隔离承诺，必要时切零保留档或自托管。

### 8. Warp 披露数据泄露 + OpenCode 入侵致 API key 泄露
- 摘要：Warp 因第三方供应商漏洞致 AI 智能体日志与遥测或受影响（分析称攻击由「智能体集群」驱动）；同期 OpenCode 平台入侵致约 1.4% 用户存储的外部供应商 API key 泄露、部分被盗刷最高 $1,700。
- 链接：https://www.bleepingcomputer.com/news/security/warp-discloses-breach-exposing-ai-agent-logs-user-telemetry-data/
- 对前端架构师：排查团队是否在用 Warp/OpenCode 类 AI 终端与编码平台，命中即轮换其中存储的全部供应商 API key，并把「智能体日志留存策略」加入数据安全清单。

### 11. GitHub Agentic Workflows GA、Agent Merge 云端盯防 PR
- 摘要：Actions 内的智能体工作流转正；Agent Merge 在云端盯防并修复 PR；同批 Automations 新增工具/触发器/成本控制。

### 12. VS Code Agent Host 与开放协议 AHP
- 摘要：Copilot 会话与单个 VS Code 窗口解耦（关窗后台继续跑、可托管远端机器或 GitHub 云端），同一云端会话可在 app/Mobile/github.com/CLI 接续；开放 Agent Host Protocol 供第三方客户端同步。
- 链接：https://github.blog/changelog/2026-10-28-github-copilot-in-vs-code-universe-releases/
- 对前端架构师：评估「会话与窗口解耦」对开发环境标准化的影响——远端托管可统一团队算力与权限面；跟踪 AHP，判断内部工具是否值得对接。

### 13. GitHub Copilot SDK 更名 Microsoft Copilot SDK
- 摘要：开发者侧智能体 SDK 收进微软品牌线，与 Copilot app/VS Code Agent Host（AHP 开放协议）同批落地，Copilot 系智能体供给进一步平台化。
- 链接：https://github.blog/changelog/2026-10-28-github-copilot-sdk-is-becoming-microsoft-copilot-sdk
- 对前端架构师：若内部工具引用了 Copilot SDK，安排一次包名/文档/CI 引用迁移，避免旧名后续断供。

## d. 前端上游（2 条）

### 14. Firefox 159 正式发布
- 摘要：修复 Wayland 标签点击误分离与 Linux AMD GPU 内存暴涨（地图/ChatGPT 类页面受影响）；随版 MFSA 2026-118 修复高危 DOM 导航同源策略绕过（CVE-2026-117860）。
- 链接：https://linuxiac.com/mozilla-firefox-159-improves-linux-wayland-support-adds-new-tab-search/
- 对前端架构师：把团队/CI 浏览器基线升到 159（含安全修复），QA 回归清单补 Wayland/AMD GPU 场景（地图与长列表页内存回归）。

### 15. Node.js 26 转 Active LTS、发布模型自 27 起改革
- 摘要：26 按期转 Active LTS、24 转 Maintenance；新模型每年 4 月一个大版本、全部最终转 LTS，并新增 Alpha 预览阶段，26 是旧节奏最后一线。
- 链接：https://nodesource.com/blog/nodejs-release-schedule-is-changing
- 对前端架构师：盘点 47 个项目 CI 与 `engines` 的 Node 版本声明，Q4 内把可升项目迁到 26 LTS，并按新年度节奏重排明年构建链升级窗口。
