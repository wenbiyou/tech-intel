## 四、处理规则

1. **人物是线索雷达不是直接信源**：不逐人追推文，重大言论经一手媒体转述收录，链接指向可核实报道
2. **每日简报接入**：digest 任务书检索前读本文件，人物名单（第一档优先加权）+ 平台枢纽清单纳入检索词；⭐ 点评以名单内人物重大言论为优先候选
3. **深度落档**：人物重大判断/预言进 ⭐ 点评时，观点摘录落 L3 `insights/`
4. **UI 清单定位**：改版/美化/找参考任务时定向检索；Apple 设计大事件由简报「科技行业」通道自然覆盖
5. **名单冻结**：人物增删由用户发起；季度复盘仅输出降级/移除建议（连续一季无有效信号），经用户确认后执行
6. **修订纪律**：增删改一处即生效，次日简报自动应用；不回改历史决策记录
